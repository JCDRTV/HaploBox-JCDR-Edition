SOURCE: Alpha 5 Testbuild 11 FocusFollowIconsHotfix, untouched backup created

BUILT IN THIS TEST CANDIDATE (NOT YET TESTED IN WOW FOREVER)

1. CLIENT-LOCAL MINI HEAL MODE
- Large main WoW client keeps the familiar full partyframes (MAIN view).
- Each smaller client can switch independently to five extra-large HP blocks
  in one horizontal row at the bottom of its own WoW window.
- Blocks are SecureUnitButtonTemplate buttons with genuine WoW unit tokens;
  intended for @mouseover healing, not simulated/painted unit frames.
- Only character names and HP/HP percentages; absent party members have
  inert placeholder slots. Underlying party sync and follow data remain active.
- MAIN button above the row returns to the full UI.
- Click MINI HEAL in Quick Settings or type /hb view heal; return with
  /hb view main; /hb view toggle switches. Mode is local, not sent by SHARE UI.
- Mode changes are rejected during combat to avoid protected-frame changes.
  Health values refresh while in combat via native StatusBar setter.

2. CONTROLBAR + QUICK SETTINGS
- Narrow fixed Controlbar now extends to the right edge of the Focus/Follow
  indicators, not across aura icons; title remains the drag handle if unlocked.
- Four compact status icons report actual follow mode, loot method,
  auto repair and quest sharing. Gear opens Quick Settings flush to the right.
- Menu retains Direct/Dungeon selection without implicit Reapply.
- Menu retains invite, healer assignment, trade, options, auto repair,
  frame lock, safe-sell lock, and group leave.
- Menu now adds MINI HEAL and LOOT AUTO (restores auto FFA/Group selection).
- Manual LOOT click toggles actual FFA vs Group when group leader and disables
  auto loot, rather than silently using an auto-check as a manual toggle.
- Click-away closing is NOT yet implemented: it must not swallow game clicks.

3. VISUAL POLISH
- Missing Buff warning icons now approximately Focus tile height, separate
  from the existing smaller active-buff icons and HoT/debuff sizes.
- Bronze bar borders made more prominent (2px vs previous 1px).
- All Focus and Follow icon combinations from Testbuild 11 are preserved.
